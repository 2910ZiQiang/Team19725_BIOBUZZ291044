# 开题前讨论

上赛季prototype阶段期间，队员提出了许多新颖的想法，但由于责任分工与后续工作不明确，队伍陷入了各方案优劣的口头争论中，而几乎没有推进prototype制作进度，最终导致很多方案未能来得及实现

因此，在BIOBUZZ开题前，全体队员再次反思了之前prototype阶段的问题，一致同意了两条原则：

- **用数据说话**：一份真实的实验数据，其价值远大于几小时的凭空讨论。所有方案提出后，都应该先落地prototype做出实机，再通过实验收集数据，最后基于数据讨论方案的优劣。
- **谁提出，谁负责**：所有队员都参与prototype制作，但每个prototype的进度由它的**提出者**负责。在约定的期限之前，方案的提出者必须向队伍提交实验数据，以证明自己方案的优越性，否则该方案将被视为不可行

# 9/13开题会议

上赛季已经获得了炮台+单飞轮的数据，以该方案为基线，队员在开题会议上提出了以下方案：

## 1. 四球并发

用一个长条飞轮（drum）实现四个球同时发射
理论发射时间可减至1/4

理论有效射区：

- 自cell张开左右各54度（仅考虑宽度），约4块地垫
- 自cell张开左右各15度（考虑四球射程误差），约2块地垫

优越性目标：得分期望，射区占比，发射时长至少一项最优

存在电机负载过大、球体碰撞发散及射程差的风险。
​​

## 2.四球抬升​​

采用侧面抬升管状结构，向花筐内同时扔4个球

优越性目标：得分效率优于最优的发射方案

## 3.单球夹取

用外挂机械夹爪抓取nectar，无需预留大球进入车内空间。

可行性目标：能稳定抓取即可

## 4.windmill推球

用windmill推球，可实现大小球兼容

优越性目标：得分期望，射区占比，发射时长至少一项最优

# 验证计划​​

​​设定验证时间节点​​：所有关键方案的原型机必须在10月1日前完成初步测试并获得数据，否则不再考虑后续开发。

​​分配专项测试任务​​：针对不同方案的核心技术难点，由方案的提出者负责对应的原型机制作与验证工作。

# 后续计划

- 并发成功：
  - 夹取成功：采用并发+夹取
  - 夹取失败：只采用并发
- 并发失败：
  - windmill推球成功：
    - 夹取成功：采用windmill推球+夹取
    - 夹取失败：只采用windmill推球
  - windmill推球失败：
    - 抬升成功：采取单发+抬升
    - 抬升失败：
      - 夹取成功：采用单发+夹取
      - 夹取失败：只采用单发

# 9/22

经计算，若使用四球并发，飞轮质量将达到1.1kg，加速需要约1s时间。根据上赛季经验，该时间会极大浪费比赛时长，并增大发射过程中受到干扰的可能性。因此，最终决定放弃4球并发方案，但继续考虑测试更保守的双球并发方案。

# 9/26

经实验，大球抬升的得分效率低于发射的得分效率，因此最终决定放弃四球抬升，改为大小球双发射口。
经计算，大小球双发射口的得分效率约为双球并发的1.1倍，故放弃双球并发方案，考虑大小球双发射口+夹取

# 9/30

经计算，大小球发射和夹取不能共存，电机不够；经模拟器（由FTC6603开发，19725进一步改进）测试，得分效率：大小球发射>单发+夹取>双球并发。最终决定10月制作大小球双发的木板整车，进入结构测试阶段。

# 10/1

工程完成初步设计，确定使用Y字形球道+胶轮物理分球+大小双炮台设计，并决定采用“飞轮套电机"的设计，节省炮台空间。
工程与程电开会讨论结构设计与电器位置，确认：Intake电机装在右侧三角空隙，Control Hub与平转电机装在后侧梯形空隙，Expansion Hub装在底板下，扳机舵机装在两侧板外侧，limelight连接顶板。

# 10/2

工程继续开会，讨论球道胶轮具体尺寸与设计，最终确定使用较大的胶轮，顶部裸露并突出顶板。满足分球功能的同时，便于弹开意外落到顶部的球。同时，在intake前放一个可旋转抬升的铲子，用于在自动阶段吃flower。

# 10/9

工程开始搭建木板车，完成了intake外侧结构搭建，并测试确认了容纳球量上限。

# 10/10

程电测试后确认了压敏电阻的准确位置，完成了相应的压敏电阻读数程序。

# 10/13

工程完成intake并测试，发现胶轮会产生较大形变；改变胶轮设计，采用辐条形状

# 10/15

工程重新测试球道，发现分球挡板过软，改用金属梁
工程完成大球炮台，并由程电测试，等速等仰角最大命中率0.5
程电开始改进上赛季的飞轮速度控制算法，用ds hareness自动收集数据并总结结论，发现：
![alt text](Tuning/results/9a65c7a3758a8d4e549f4d919c680b02.jpg)
稳态占空比与转速不过原点。实测 8 个稳态工作点，两者满足 d\_ss(ω) = kS + kff·ω，回归 R² = 0.9949、残差 0.98% 占空比。其中 kS 对应静摩擦、同步带预紧与齿槽转矩，这部分占空比只用来“推动”机构、不产生转速。若仍用单一 kff 过原点拟合，低转速段欠给、高转速段过给，差额会全部压给积分项（实测各工作点 I 项长期停在 −0.04\~−0.06）。

# 10/16

工程重新测试球道，发现球的孔洞会卡在金属梁中；重新设计分球装置

程电发现球道设计改变后压敏电阻失效；改用光电门传感器，并完成了其驱动程序，由工程设计其支架

程电改进了飞轮速度控制算法，改为**duty = kS·sgn(ω\*) + kff·ω\* + kp·e + ki·∫e + boost**，所有增益都以**占空比**为量纲，且只有误差回到阈值以内（已进入稳态）才允许触发，目标转速一变立即解除武装，触发时同时清积分。

# 10/21

工程重新测试球道，失败，最终决定重画整车
程电继续改进控制算法，加入了阶跃，提高了炮台的响应速度和精度。并在再次测试中取得了良好的效果，炮台的响应速度和精度均有明显提升，实际转速稳定在目标转速的±10tick/s以内，且在连续发射过程中能够保持稳定的转速和精度。
