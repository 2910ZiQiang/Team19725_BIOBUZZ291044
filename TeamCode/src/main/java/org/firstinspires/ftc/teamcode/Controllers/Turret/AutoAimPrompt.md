修改Turret, 实现自动瞄准功能：
重载update函数，输入小车位置，是否允许发射和是否强制释放两个扳机，自动计算目标参数（平转角度、两个俯仰角度、两个发射器速度），通过手动的update更新平转角度，若允许发射则将计算速度设置为目标发射器速度并设置对应仰角，否则目标发射器速度和仰角均设为预载值。
平转角控制如下：
不论是否正在发射，都实时计算当前发射的目标平转角度，若未超过范围则设为目标值，否则设为最接近的边界。
预载算法如下：
位于不可发射区（已知的凸多边形）时，预载速度值为0，仰角为最小值，否则实时计算当前发射的目标速度和仰角，若未超过设定的最大预载速度则设为预载速度值和仰角值，否则设为最大预载速度和最大仰角值。
预载功能可以由操作手手动关闭，此时预载速度值恒为0，仰角恒为最大值。
当前球门位置从RobotPosition获取。
每个Shooter内部的计算逻辑如下：
根据球门位置，车辆位姿和发射器相对位置，计算发射器的实际位置，得出需要的平转角（0度对应指向车头，逆时针为正）和射程
仰角允许取有限个离散取值，对应舵机位置均已知，每个仰角对应一组射程范围和一组线性回归模型，选取范围合适的仰角，根据射程计算对应的飞轮速度。若有多个仰角范围都包含射程，取对应飞轮速度最小的仰角。
每个Shooter内部解算完成后，向上传给Turret，Turret根据计算结果更新目标参数，其中平转角度取两个发射器的平转角度的平均值（指向两个平转角夹成的劣角，若超限则维持当前发射/预载的转速与俯仰但始终不释放扳机，直到平转角恢复可行），其余参数各自设置。若计算得到的飞轮速度超过对应的speedMax，将其设为0。当某个Shooter的机构与平转角均达到目标时，自动释放对应的扳机，除非被强制释放。
