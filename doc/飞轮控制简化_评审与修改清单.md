## 2. P0 —— 必须改（合入前完成）

### P0-1 积分门限：恢复「两档 + 相对缩放」

**位置**：`utility/Shooter/FlywheelCalculator.java:222-228`（掉速状态机）、`:258`（积分累加条件）、`utility/Shooter/FlywheelParams.java:139,181`（`iZone`）

**现状（`c8c0735`）**：一个绝对阈值 `iZone=120 tick/s` 同时承担两个角色——"现在是不是真实瞬态"和"该不该积分"。

**为什么不行**：两个角色对阈值的要求相反。

- "是不是瞬态"要宽：阈值贴着量化噪声（σ ≈ 10~20 tick/s）会频繁翻转；
- "该不该积分"要窄：积分一旦在恢复尾段累加，就变成过冲。

代码现值落在"宽"这一侧，代价可由代码常量直接算出（⚠️ 假设见附录 A）：

```
闭环时间常数      τ_cl = 1/(kp·Kd) = 1/(1.9095e-3 × 2611) = 0.20 s
门限内积分电量    Q    ≈ G · τ_cl
积分项峰值        iTerm = ki·Q
积分造成的过冲    Δω   ≈ iTerm/kp = ki·G/(kp²·Kd)
```

| 门限宽度 G | Q | iTerm | 过冲（仅积分贡献） |
|---|---|---|---|
| 40（= `eBand`@1700，master） | 8.0 | 0.021 | **≈11 tick/s** |
| 120（= 当前 `iZone`） | 24 | 0.062 | **≈33 tick/s** |

同一个 `kp/ki`，仅因门限放宽到 3 倍，过冲涨到 3 倍——从"半个量化台阶"变成"1.6 个台阶"。

**改成**：

```java
// ── FlywheelParams.java ──
// 删除：public double iZone;   // 绝对 tick/s
// 新增：
/** 进入瞬态的阈值（倍 eBand）：|e| > iZoneFrac·eBand → 瞬态；|e| < eBand → 退出（滞回） */
public double iZoneFrac = 3.0;
// 并在 BIG / SMALL 两个 static 块中删除 `BIG.iZone = 120.0;` 之类的赋值

// ── FlywheelCalculator.java ──
// 132 行附近：把 inDrop 改名为 inTransient（语义更准，且不再需要清除清除计时器）
private boolean inTransient = false;

// 替换 222-228 行：
if (targetVel == 0) {
    inTransient = false;
} else if (Math.abs(errorRaw) > iZoneFrac * eBand) {
    inTransient = true;                       // 进：3×eBand
} else if (Math.abs(errorRaw) < eBand) {
    inTransient = false;                      // 出：1×eBand（滞回）
}

// 替换 258 行：
integralActive = targetVel != 0 && !inTransient && Math.abs(errorRaw) < eBand;
```

**注意**：`inTransient` 对积分门控是"冗余但必要"的——积分已经用 `|e| < eBand` 卡住，但 `inTransient` 还要给 **P0-2 的电压冻结**和遥测用，所以必须保留这个 boolean。

**验收**：
- `FlywheelRun`：`0 → 1600 → 1900`，每点 ≥2 s，再打 6~8 发；
- 发射过冲 ≤ **+20 tick/s**；回带中位 ≤ **0.43 s**；
- 稳态 `duty_sd` 不高于改动前（±0.002 以内）。

### P0-2 母线电压：滤波与归一化不能"只删一半"

**位置**：`FlywheelCalculator.java:237-246`（`updateBusVoltage` + `vScale` 计算）、`:383-416`（`updateBusVoltage` 实现）、`FlywheelParams.java:185-194`（电压组）、`FlywheelCalculator.java:126`（`vBusFilt` 字段）

**现状（`c8c0735`）**：删掉了电压低通、掉速期冻结、0.6 s hold-off，但**保留了 `useVoltageNorm = true`**，于是 `s = clamp(12 / V_bus_raw, 0.85, 1.25)`。

**为什么是本次改动里最严重的一处**（全部由参数算出，不需要任何文档）：

1. `vScaleMax = 1.25` ⇒ 只要母线低于 `12/1.25 = **9.6 V**`，`s` 就顶到 1.25。
2. 此时前馈为 `ff = 1.25·(kS + kff·ω*)`，令 `ff ≥ 1` 得
   **`ω* ≥ (1/1.25 − kS)/kff = 2012 tick/s`**。
   即：在 **2050 / 2250** 这两个真实工作点上，发射/加速把母线拉到 9.6 V 以下时，**纯前馈就把 duty 顶满，P 项完全失去把输出压下来的权限**。
3. 退饱和点被推走多远（以 1700 为例）：

| 母线 | `s` | `ff` | `e_desat = (1−ff)/kp` |
|---|---|---|---|
| 12.4 V（正常） | 0.968 | 0.659 | **179 tick/s** |
| 9.6 V（发射跌落） | 1.25 | 0.851 | **78 tick/s** |

多出来的 0.19 占空比 ≈ `0.19/kp = **100 tick/s** 的"等效 boost"。被删掉的 boost 上限是 `boostMax = 0.4`（≈210 tick/s），**原始电压归一化在恢复期自己造回了其中约一半，而且没有时间上限**——它持续到电流回落、母线弹回为止，并构成一条正反馈：duty↑ → 电流↑ → V_bus↓ → s↑ → duty↑。

**改成（二选一，推荐 A）**：

**方案 A（推荐）：恢复最小电压调理 = 低通 + 瞬态冻结，不要 hold-off 计时器**

```java
// ── FlywheelParams.java ──
public double tauBus = 1.0;          // 保留
// 删除：busHoldOffSec / busFreezeTimeoutSec 两个字段及其实例赋值

// ── FlywheelCalculator.java ──
// 字段区：删除 vFrozenT / busHoldT / voltageFrozen，只留 vBusFilt（初值 NaN 表示未采样）
private double vBusFilt = Double.NaN;

// 替换 237-246 行（原 updateBusVoltage 调用 + vScale 计算）：
if (!inTransient && validVoltage(vBus)) {          // 瞬态期间保持上一有效值 = 冻结
    if (!validVoltage(vBusFilt)) {
        vBusFilt = vBus;                            // 首帧直接播种，避免从 0 爬升
    } else {
        double alpha = dt / (tauBus + dt);
        vBusFilt += alpha * (vBus - vBusFilt);
    }
}
vScale = 1.0;
if (useVoltageNorm && validVoltage(vBusFilt)) {
    vScale = vBusNominal / vBusFilt;
    if (vScale < vScaleMin) vScale = vScaleMin;
    else if (vScale > vScaleMax) vScale = vScaleMax;
}
```

代价：**1 个状态、1 个参数、0 个计时器**（比 master 的版本更简单，但保留了"区分电池电量与单发跌落"这一唯一关键能力）。

**方案 B（最小改动，零新代码）**：`BIG.useVoltageNorm = false; SMALL.useVoltageNorm = false;`
理由：`s ≡ 1` 时 `ff` 恒定、`e_desat` 固定，最多只是"跨电量前馈不准"，由积分慢慢吃掉，**不会产生过冲**。反之，"保留归一化 + 删掉滤波"是本 commit 里唯一自相矛盾的组合。

**验收**：
- `VoltageSweep`：四档 `{10.5, 11.0, 11.5, 12.0}`，同目标 `duty·V_bus` 跨电压偏差 ≤ **3%**（这是沿用代码自己 `VoltageSweepOp` 里的判据）；
- 发射段遥测里 `vscale` 在跌落期间应**保持不变**（方案 A）；或恒为 1.000（方案 B）。

### P0-3 积分冻结：恢复超时兜底

**位置**：`FlywheelCalculator.java:258-271`（积分分支）

**现状（`c8c0735`）**：`|e| ≥ iZone` 时积分"冻结"且**永不清理**。若积分曾顶到 `maxI=0.3`（堵转、卡球、目标不可达），随后误差回到带内，会带着 0.3 占空比的积分量回归，瞬时冲击量级 `0.3/kp ≈ 157 tick/s`。

**改成**：

```java
// FlywheelParams.java：加回安全阀参数（唯一一个计时器）
/** 积分最长冻结时长 (s)：超过即清零，防止"积分永久停在 maxI" */
public double iFreezeTimeoutSec = 1.5;

// FlywheelCalculator.java：
private double iFrozenT = 0;    // 冻结累计时长

// 替换 258-271 行的积分分支：
integralActive = targetVel != 0 && !inTransient && Math.abs(errorRaw) < eBand;
if (integralActive) {
    integral += errorFilt * dt;
    iFrozenT = 0.0;
} else if (targetVel == 0) {
    integral = 0.0;
    iFrozenT = 0.0;
} else {
    iFrozenT += dt;
    if (iFreezeTimeoutSec > 0 && iFrozenT >= iFreezeTimeoutSec) {
        integral = 0.0;         // 兜底：不允许积分永久失效/永久负重
        iFrozenT = 0.0;
    }
}
```

**验收**：`FlywheelRun` 或 `TuneGen4Op` 里人为压住飞轮 3 s 再松开，观察 `I integral` 在 1.5 s 后归零、恢复过程无冲击。

## 4. P2 —— 收尾与流程

### P2-1 速度 EMA 的 A/B 协议（决定删或留）

不预设结论，用一次实验裁决。两版代码都在 git 里，`FlywheelRun` 现有 15 个遥测键足以覆盖。

```
对象：飞轮台架（同电池、同负载）；目标序列 0 → 1600 → 1900，每点稳定 20 s，然后打 6~8 发。
记录：target, velocity, duty, error, integral, pTerm, iTerm, ffTerm, vscale, inTransient, iactive, settled
判据（四个数，全部由这四列算出）：
  ① 稳态 v_sd          —— 发射时刻速度一致性（最重要）
  ② 稳态 duty_sd       —— 量化极限环 / 电流纹波
  ③ 发射过冲            —— 恢复期峰值 − 目标
  ④ 回带中位/最大        —— 恢复时间
裁决：若 ① 的劣化 ≤ 0.5 个量化台阶（10 tick/s）且 ② 仍在 0.025 以内 → 可以接受删除；
      否则保留 EMA（它只有 15 行、1 个状态）。
```

⚠️ 工程判断（供参考，非结论）：master 的 `tauForError` 是**误差调度**的——`|e| ≤ 20` 用 55 ms，`|e| ≥ 60` 用 12 ms。也就是说它在真实冲击段（大误差）几乎不滤，只在稳态起效。因此"删滤波器会让掉速响应更快"这个理由基本不成立（掉了也快不了，因为τ本来就已切到 12 ms）；**删它主要损失的恰好是发射那一刻的稳态平滑**，而那是这项指标的全部意义所在。

## 附录 A：本文用到的公式与假设

⚠️ 推算前提（若不成立，量级会变但方向不变）：

1. 对象在稳态附近可线性化为一阶：`ω = Kd/(1+τ_p s)·duty`；
2. 静态增益 `Kd = 1/kff = 2611 tick/s per unit duty`（这是前馈模型 `d_ss = kS + kff·ω` 的定义，不是测量值）；
3. `kp·Kd = 4.99 ≫ 1`，故 PI 的准静态响应可用 `Kd·kp` 近似；
4. 控制周期取 `dt ≈ 8.7 ms`（仅影响 §2.1 的 α 与抖动比）。

推导：

```
闭环时间常数        τ_cl = τ_p/(kp·Kd) ≈ 1/(kp·Kd) = 0.20 s
门限内积分电量      Q ≈ G·τ_cl
积分项峰值          iTerm = ki·Q = ki·G/(kp·Kd)
积分造成的准静态过冲  Δω = Kd·iTerm/(1+Kd·kp) ≈ iTerm/kp = ki·G/(kp²·Kd)

EMA 噪声抑制比       σ_filt/σ_raw = √(α/(2−α))，α = dt/(τ+dt)
   τ=55 ms, dt=8.7 ms → α=0.1366 → 比值 0.271（即滤波后噪声为 27%）

电压归一化临界点      s 顶到 vScaleMax 的电压：V = vBusNominal/vScaleMax = 9.6 V
  前馈自饱和转速      ω* = (1/vScaleMax − kS)/kff = 2012 tick/s
  退饱和点            e_desat = (1 − s·(kS + kff·ω*))/kp
  等效 boost          Δff/kp
```
